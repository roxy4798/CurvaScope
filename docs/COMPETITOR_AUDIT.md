# Competitor and differentiation evidence

Audit status: preliminary, not a market-wide competitor study. No uniqueness or superiority claim is supported by the research completed for this release.

## Observed product evidence

- CurveProof has a requirements wizard, reusable illustrative recipe examples, approximate curve charts, side-by-side three-recipe comparisons, selected local validation, optional read-only SDK state lookup, and an Invent readiness checklist.
- Meteora Invent's inspected repository provides JSONC DBC configuration and CLI workflows for configuration and pool actions. It is CurveProof's relevant official configuration tool. CurveProof does not currently serialize a complete Invent configuration and does not replace Invent.
- Other competitor rows previously included unsupported feature-exclusion and market claims. Those have been removed rather than repeated without current evidence.

## Product hypothesis

The testable differentiation hypothesis is that requirements-first intake plus transparent approximate comparisons can help a developer reason about candidate DBC parameters before completing an official Invent configuration. This is a product hypothesis, not proven user value. No user research, comparative usability study, endorsements, adoption, or launch volume are available.

## Product boundaries

All presets are illustrative engineering examples, not Meteora-endorsed, profit-optimizing, optimal, guaranteed to graduate, or financial advice. Charts are analytical estimates; the product uses qualitative parameter trade-offs and no composite score. Export remains disabled pending a complete official-compatible serializer and safe validation path.
